# RPA 預錄證據

以下檔案由講師使用起始版、本機模擬網頁與虛構資料實際執行產生，供無法啟動瀏覽器的學員分析。日誌中的工作目錄已替換為 `<workshop>`。

| 檔案 | 內容 |
|---|---|
| `rpa-delay.log` | 預設 1200ms 顯示延遲下的失敗日誌 |
| `rpa-delay.png` | 同次失敗時的畫面 |
| `rpa-fast.log` | 零延遲執行日誌及獨立摘要比對結果 |
| `rpa-fast.json` | 零延遲執行的實際輸出，不是正確答案 |

分析任務：

1. 哪些內容是直接觀察到的事實，哪些只是推測？
2. 為什麼程式可以結束，摘要卻不一定正確？
3. 下一個最小驗證步驟是什麼？

正確結果仍以 `fixtures\expected_summary.json` 為準。只閱讀這些證據不代表已修復程式，請在作業單記錄「尚未完成執行驗收」。
